# 要件定義書の目次チェック

対象は `requirements.md`(タスク管理、合意済み 2026-11-01)で、観点は `requirements-toc.md` である。

判定は次の 4 値とする。

| 判定 | 意味 |
|---|---|
| 値あり | 値が書かれている |
| 未決 | 未決事項(Q)になっている |
| 該当なし | 該当なしと書かれている |
| 欠けている | 値も未決事項も「該当なし」の記載も無い |

1 つの節に複数の項目があるときは、項目ごとに判定した。要件定義書の節番号は目次と一致しないので、根拠には実際の節と要件 ID を書く。OI は `open-issues.md` の候補 ID である。

## 節単位の結論

全項目が値ありの節は、1.1、1.2、2.1、6.4、8 の 5 つである。

全項目が欠けている節は、1.3、2.2、3、4、5.5 の 5 つである。

残りの 8 節は、値・未決・欠けが混在している。5.1、5.2、5.3、5.4、6.1、6.2、6.3、7 が当てはまる。6.3 は全項目が値ありだが、細部に不足があるのでここに含めた。

要件定義書のレビューチェックリストは「決まっていないことが、要件ではなく未決事項に書かれている」にチェックが入っている。しかし上の「欠けている」項目のうち、未決事項に載っているものは無い。

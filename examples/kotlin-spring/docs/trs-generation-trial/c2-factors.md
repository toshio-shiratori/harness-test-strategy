# 因子・水準（テンプレート §4）

## 表記

- `⟨U+XXXX⟩` は、その符号位置の 1 文字を表す。
- 「White_Space」は Unicode の White_Space 属性を持つ文字、「DICP」は Default_Ignorable_Code_Point を持つ文字である。範囲の根拠は OI-017。
- 「組になる文字」は OI-017 の 356 個である。異体字セレクタ 260 個（U+180B〜180D、U+180F、U+FE00〜FE0F、U+E0100〜E01EF）と、タグ文字 96 個（U+E0020〜E007F）である。
- 「表示される文字」は OI-017 の定義による。空白でも表示されない文字でもない文字をいう。
- 例の基準日は 2026-11-10（Asia/Tokyo）とする。
- 字数の例は、結合文字と国旗に限る（OI-008）。
- 区分の「有効（未決）」は、期待結果が入力から決まらない水準である。`c2-undecided.md` の U 番号を備考に書く。

**組合せ生成方針**

| 対象 | 方針 |
|---|---|
| 登録の入力（F1〜F7） | タイトルと期限は独立に判定するので、全組合せにしない。各水準を単独で 1 回使う。理由が同時に出る組合せだけ、代表の行を足す（C-65〜C-69） |
| タイトルの除去と字数（F4 × F5） | 順序が結果を変える組合せだけを行にする（C-45〜C-49） |
| 区分（F8 × F9） | 全組合せ。F10 は F9-L4・F9-L5 とだけ組み合わせる |
| 状態の操作（F8 × F9 × F11 × F12） | F12-L1 は F8 × 「期限切れか否か」× F11 の全組合せ。F12-L2・L3 は F11 と全組合せ |
| 並び順（F15 × F16） | F15-L2・L4 は F16 と全組合せ。ほかは F16-L1 だけ |
| 表示の選択（F13 × F14） | 各水準を単独で使う |
| `PBT` の水準 | Property に任せ、§5.2 には境界値の行と、Property の対象を示す行だけを置く |
| F6-L4、F10-L1 | §5.2 の条件に単独では書かない。F6-L4 は F7 の各水準の前提で、F10-L1 は区分の行の既定の条件である |

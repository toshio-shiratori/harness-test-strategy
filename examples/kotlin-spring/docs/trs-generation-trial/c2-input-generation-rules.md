# 生成の規則

期待結果と受入条件を生成するときは、次の規則に従う。

| 番号 | 規則 |
|---|---|
| G1 往復 | 保存や取得を伴う振る舞いには、層1 の AC に加えて、HTTP か DB を通した往復を確かめる AC を層2(Integration)に置く。取得の応答の中身も、この往復に含める |
| G2 副作用 | 拒否と失敗の組合せでは、期待結果と AC に、状態が変わらないことを書く。状態を変える操作が成功する組合せでは、操作の対象外の属性と対象外のデータが変わらないことを書く |
| G3 拒否の水準 | 拒否に至る水準ごとに、層2 の AC か、その例を最低 1 つ置く。例の値は因子表の水準から取る |
| G4 観測できる要素 | 期待結果と Then には、観測できる要素をすべて書く。既定で決まる値、表示に現れる値、読み戻した状態を含める |
| G5 E2E の選び方 | 層2(E2E)の AC は、02c の §5 を切り出した入力ファイルの規則に従って選ぶ。AC の検証層には、当たる許可領域を書く。許可領域に当たらないものは E2E にせず、下の層に置く |

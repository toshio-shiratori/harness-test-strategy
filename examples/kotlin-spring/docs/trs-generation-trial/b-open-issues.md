# Open Issue の候補

要件定義書 `requirements.md` から答えが出ない点の一覧である。AI の推奨は判断の材料で、決定ではない。決定はオーナーが行う。

- 区分は、その点が決まらないと AC の期待値を書けないものを `Blocking` とした。AC の期待値に影響しないものと、書き方の確認にとどまるものは `Non-blocking` とした。
- ID は候補の番号である。AC は未起草なので、Blocking の候補には TRS へ起票するときに関連列へ AC を書き、その AC に `@pending:<OI-ID>` を付ける。
- OI-001〜003 は、要件定義書の未決事項 Q-19〜21 である。起票したら要件定義書の OI-ID の欄に番号を書く。

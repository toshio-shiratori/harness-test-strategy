# 因子・水準の案(TRS テンプレート §4 の形)

要件定義書 `requirements.md` から起草した案である。この表で仕様を新しく決めない。

- 備考の `REQ-TODO-nn` の nn は、水準の根拠である。
- 備考に OI を書いた水準は、期待値が未確定である。OI は `open-issues.md` の候補 ID で、決定まで期待値を置かない。
- 区分の「有効」「無効」は、要件から読める範囲で付けた。未確定の水準は「未確定」とする。

**組合せ生成方針**(案)

| 対象 | 方針 | 理由 |
|---|---|---|
| F11 × F12 × F15 | 全組合せ | 表示区分と操作の核で、OI-005〜008 の期待値が揃えば行数も少ない |
| F1 × F4 | 境界の 50 字・51 字に絞り、全組合せ | 数え方の誤りはこの境界に出る |
| F2, F3, F5 | 因子ごとに単独で展開する | 入力の検証は互いに独立と見てよい。ただし OI-010 の決定で F2 と F5 の組合せが要るなら足す |
| F9 × F10 | F9 の有効な水準にだけ F10 を組み合わせる | 無効な期限には今日との関係が無い |
| F12 × F13 | 境界の F12-L4, L5 を全組合せ | タイムゾーンの誤りは 0 時の境界に出る |
| F18 × F19 | 全組合せ | F19-L3 は OI-039 の決定後に足す |
| F20 × F18 | ペアワイズ | 一覧の並びと表示の切り替えの組合せ |
| その他の因子 | 単独で展開する | 他の因子と独立と見てよい |

因子制約(テンプレート §5)は、今回の依頼の範囲外なので作っていない。未確定の水準は OI の決定後に §5.2 へ期待結果を書く。

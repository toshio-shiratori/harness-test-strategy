# 4. 因子・水準

表記の約束は次のとおり。

- `[U+200B]` は、その 1 文字を表す。`[半角空白]` も同じである。
- 「空白」は White_Space 属性の文字、「表示されない文字」は Default_Ignorable_Code_Point の文字を指す(OI-017)。
- 「組になる文字」は、異体字セレクタ 260 個とタグ文字 96 個の合計 356 個を指す(OI-017)。
- 「表示される文字」は、空白でも表示されない文字でもない文字を指す(OI-017)。
- 字数は、拡張書記素クラスタで数える(REQ-TODO-15、OI-008)。
- 区分の `未決` は、期待結果を決められない水準である。[undecided.md](./undecided.md) の U-ID を備考に書く。

**組合せ生成方針**

- 登録の入力は、F1×F2 を制約表の行だけ展開する。F3、F4、F5、F7 は 1 因子ずつ展開する。
- タイトルの理由と期限の理由が同時に起きる組合せは、F3 の代表 × F7 の無効水準の代表と、F1-L4 × F7 の無効水準の代表に絞る(C-120、C-121)。理由の判定は互いに独立だからである。
- F8×F9 は全組合せ、F12×F13 は全組合せとする。
- F10、F11 は、F9-L4 と F9-L5 の時刻だけと組み合わせる。
- F15×F16×F17 は、制約表の行だけ展開する。連続値の PBT は、並びの性質の検査に任せる。

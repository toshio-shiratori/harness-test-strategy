# 要件定義書の目次(確認の観点)

要件定義書は、次の各節について「値が書かれている」「未決事項(Q)になっている」「該当なし」のどれかになっていることを求める。

| 節 | 書くこと |
|---|---|
| 1.1 目的 | 何のための機能か |
| 1.2 対象範囲 | 対象の機能 |
| 1.3 範囲外 | 対象にしないもの |
| 2.1 利用者 | 利用者とその説明 |
| 2.2 用語 | 語の定義 |
| 3 前提と制約 | 前提条件、変えられない制約 |
| 4 業務フロー | 業務の流れ |
| 5.1 できること | 利用者ができること。優先度 |
| 5.2 入力項目 | 項目ごとの型、形式、範囲、必須か、空の扱い |
| 5.3 状態と操作 | 状態の一覧、操作ごとの遷移、対象が存在しないとき |
| 5.4 画面に見せるもの | 区分の表示、文言、操作後の画面の状態 |
| 5.5 外部連携 | 外部システムとのやり取り |
| 6.1 拒否の振る舞い | 拒否の条件と、利用者への伝え方 |
| 6.2 順序と同値 | 並び順、同じ値のときの決め方 |
| 6.3 環境の条件 | 時刻、タイムゾーンなど、結果を変える外部条件 |
| 6.4 その他のルール | 上に当てはまらない業務の決まり |
| 7 非機能要件 | 性能、安全性など |
| 8 未決事項 | 決まっていない問い |

# 因子・水準の案: タスク管理（登録・完了・一覧と期限）

入力は要件定義書（合意済み 2026-11-01）である。TRS テンプレートの §4 の形で書く。

- 水準の期待結果は、ここでは決めない。期待結果はテンプレートの §5.2 で、AC と Open Issue を根拠に書く。
- 備考の `OI-xxx` は [open-issues.md](./open-issues.md) の候補を指す。OI の付いた水準は、その決定によって有効・無効が変わるか、水準そのものが無くなる。区分は「未確定」とした。
- AC はまだ起草していないので、備考の根拠は要件 ID で書く。
- 区分の「境界」「同値」は、同値分割と境界値のどちらの水準かを示す。

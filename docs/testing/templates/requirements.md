# 要件定義書: <機能名>

> 使い方: このファイルを `<機能ID>-<機能名>.md` としてコピーして使う。置き場所は導入先の要件定義書ディレクトリ（例: `docs/requirements/`）。
> 山括弧 `< >` と `例:` の行は置き換え／削除すること。この要件定義書は、TRS を起草するときの入力になる。書く範囲は [03 §5](../03-trs-guideline.md#5-策定フロー) に従う。
> **要件には ID を付ける。ID は TRS の US/UC の「出典（要件 ID）」に書き、対応を CI が検査する（[03 §3.4](../03-trs-guideline.md#34-トレーサビリティ)）。**

| ID | 観点 | 要件 |

| REQ-CNL-04 | `<例: 認可>` | `<例: 注文の購入者本人だけが、その注文をキャンセルできる>` |
